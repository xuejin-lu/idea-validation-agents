# DEMO／SYNTHETIC DATA：會計專業人士交接清單

本檔案只使用虛構資料，不能作為記帳、報稅、收入認列、發票處理或任何專業結論。

## 已整理的資料索引

- `DEMO-SHOP-202608`：虛構銷售／平台來源，對應 `normalized_demo.csv` 的 `source_file_id`。
- `DEMO-BANK-202608`：虛構銀行結算來源；示範資料故意缺少一筆結算列。
- `DEMO-001-001`：示範可由來源 ID 與來源列回溯的 matched item。

## 待專業人士確認

- `EX-DEMO-001`：平台費差異 12；尚未判斷其正式帳務或稅務處理。
- `EX-DEMO-002`：退款／折讓 300；退款原因與證明尚未確認。
- `EX-DEMO-003`：預期入帳 570 找不到虛構銀行來源列。
- 所有 `expected_net` 只是 gross、platform_fee、refund_amount 的機械比較欄位，不是收入、費用、稅額或應收款結論。

## 交接時應附上的材料

- 原始來源檔的實際版本與期間（由買方提供）；
- 去識別化後的來源／列索引；
- 買方對退款、手續費、發票與入帳的背景說明；
- 專業人士對正式帳務、稅務或發票處理的判斷與後續要求。

本 demo 不包含任何真實公司、客戶、帳號、發票或銀行資料。
