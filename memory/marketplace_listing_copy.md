# Marketplace Listing Copy

## 標題

一個月多通路電商資料整理與差異清單（非記帳報稅）

## 內文

你是否同時使用官網與多個電商/金流通路，每月需要把訂單、入帳、發票、退款或折讓資料整理後交給記帳士或會計師？

我提供一個月、固定範圍的「多通路對帳準備包」：

- 收集你提供的 CSV/XLSX/PDF 或既有報表；
- 將資料整理成一份可追溯的工作表；
- 依事先確認的欄位標出訂單、入帳、發票、退款/折讓差異；
- 產出差異清單、來源索引與交給你既有記帳士/會計師的 handoff checklist。

這是資料整理與差異準備服務，不是記帳士或會計師服務；不提供稅務申報、稅務建議、正式記帳、簽證、法律意見或合規保證。若需求涉及正式帳務或稅務判斷，請由你的合格專業人員審閱。

初步流程：

1. 先說明使用的平台、月份與想解決的差異；
2. 提供一小段已遮蔽個資的樣本；
3. 確認固定範圍與交付欄位後，再提供報價與可開始日期。

請不要傳送密碼、OTP、完整信用卡資料、未遮蔽身分證/地址/電話或銀行登入資訊。若你願意，請在訊息中回答：「平台數量、月份、目前最困擾的差異、是否可提供去識別化樣本」。
