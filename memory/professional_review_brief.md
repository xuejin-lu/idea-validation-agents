# 台灣專業邊界審查問題單

請交給台灣合格記帳士、會計師或稅務專業人士審閱。這是一份問題清單，不是本專案對法律或專業邊界的回答。

1. 「收集買方提供的去識別化平台／金流／銀行匯出檔、整理欄位、做機械性的金額與來源比對、列出未決差異、準備交給買方既有專業人士的 handoff checklist」是否可能跨入台灣受規範的記帳、會計或稅務代理範圍？請指出具體觸發點。
2. 下列文案哪些字眼應刪除或改寫：對帳、月結、發票、退款／折讓、應收、費用、淨額、差異找回、交給會計師？請提供安全的替代文字。
3. 哪些輸出欄位或判斷必須由合格專業人士審閱？例如 `expected_net`、平台費差異、退款／折讓分類、發票對應、收入或費用認列。
4. 在不提供正式記帳、申報、稅務建議、簽證／簽章或法律意見的前提下，接受「一個月、固定範圍、資料準備與交接」的付費服務，是否可行？需要哪些前置條件？
5. 最低限度的報價／服務條款、責任限制、專業審閱、資料最小化、暫存與刪除措施應包含什麼？
6. 哪些情況應一律拒絕或轉介，例如要求後台登入、代申報、正式傳票、保證合規、處理未遮蔽個資或代替會計師作判斷？
7. 是否建議在取得專業審查意見前，只做上架與承諾測試而不接收真實資料？若否，安全的最小範圍是什麼？
