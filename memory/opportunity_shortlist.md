# Opportunity Shortlist

## Research constraints

- Market is Taiwan-first; foreign evidence was not used to qualify candidates.
- Founder defaults: 1–3 person team, NT$0–5,000 validation budget, up to 3 months, online reach, no cold calling/email as the primary channel.
- This run does not recommend building software or running a paid pilot. Tests below are demand/commitment tests using a public offer, intake form, sample workflow, or request for a live document.
- Evidence labels: Observed = directly supported; Inferred = interpretation; Estimated = explicit calculation; Unknown = not yet supported.

## Decision summary

The best problems to test first are narrow, service-led workflow bottlenecks with an existing Taiwan payment anchor. The leading candidate is government-tender bid readiness for one vertical, followed by food-label preflight if a licensed practitioner can be attached. Multi-channel e-commerce reconciliation is real but more crowded. Payroll close is recurring and monetizable but has the highest trust, privacy, and compliance burden.

## Candidate A — 標案文件預檢與適投篩選（先選一個垂直）

- Target user: 台灣 IT 服務、活動／行銷、顧問或專業勞務公司的負責人／標案行政人員。
- Economic buyer: 公司負責人，因為他承擔投標工時、押標金、失格風險與得標後營收機會成本。
- Problem: 每個案件要閱讀資格與規格、整理多種證明／切結／報價／服務建議書並趕期限；不確定是否適投的案子會消耗大量時間。
- Current workaround: 老闆或行政逐案讀 PDF、沿用舊 Word／Excel，或找標案顧問／企劃撰寫者。
- Strongest evidence: [官方投標須知範例](https://www.taftw.org.tw/export/sites/taf/files/2025-B-0223-2-0.pdf)（Tier A，文件要件）、[104 標案職缺](https://www.104.com.tw/jobs/search/?keyword=%E6%A8%99%E6%A1%88)（Tier B，付費勞動）、[PRO360 標案顧問](https://www.pro360.com.tw/category/tender_proposal)（Tier B，987 則評論／需求展示）、[CITYGLOW 價格](https://citiesglow.com/)（Tier B，NT$699–5,000+ 的相鄰服務）。
- Evidence quality: A/B mix; Taiwan Evidence Gate passes.
- Value mechanism: 用一頁適投判斷＋缺件清單，把閱讀與整理時間轉成可衡量的「收到文件到產出預檢結果」時間；避免因缺件／格式問題失格。
- Why now: 2026 在地供應商已把標案推播、健檢與文件檢查商品化；這是存在的購買語境，不是新造需求。
- Main contradiction: 高品質提案仍需要產業實績與履約理解；通用 AI 讀標案很容易被現有平台與顧問複製。
- Biggest unknown: 單一垂直的每月案量與「預檢」本身的付費意願；目前只有相鄰服務付款證據，沒有本方案成交證據。
- Cheapest behavioral test: 選一個垂直，做一份繁中「投標文件完整性檢查表」與公開價格頁，透過 PRO360／標案社群／SEO 內容引流；讓訪客上傳一份公開招標文件或填寫案件條件，量測 14 天內的有效申請、完整文件上傳與要求後續的比例。不先收款、不承諾法律意見。
- Kill criterion: 14 天內至少 30 個台灣目標訪客中，沒有 3 個以上願意提交真實招標文件／案件條件，或多數只要免費範本而不願留下可交付需求，則暫停。

## Candidate B — 微型食品品牌的包裝標示前置檢查／專業轉介

- Target user: 台灣小型食品品牌、進口食品商、伴手禮／團購商家、承接食品包裝的設計公司。
- Economic buyer: 品牌負責人或產品／行銷主管；包裝重印、延誤上架與罰則由其承擔。
- Problem: 在印刷／上架前要核對品名、成分、過敏原、營養標示、原產地與宣稱用語，規範變動使「看似完成」的包裝仍可能要重工。
- Current workaround: 自行讀 TFDA 規定、沿用代工廠／設計公司範本，或找食品技師／報驗行逐件審查。
- Strongest evidence: [衛福部標示說明](https://www.mohw.gov.tw/fp-2636-21172-1.html)（Tier A，官方欄位）、[衛福部營養標示公告](https://www.mohw.gov.tw/cp-5269-70142-1.html)（Tier A，規範與罰則）、[北極星公開價格](https://startxing.com/food-label-review/)（Tier B，NT$500／3,000 起／18,880 月）、[FoodFact 價格](https://foodfact.co/tw/pricing)（Tier B，NT$1,490／份）。
- Evidence quality: A/B mix; Taiwan Evidence Gate passes.
- Value mechanism: 在印刷前找出缺欄與高風險用語，降低重印／延期；以「每件產品、交付時間、需補件數」衡量。
- Why now: 規範與營養標示要求仍是台灣食品上架的強制前置條件，且按件付費服務已存在。
- Main contradiction: 服務涉及食品安全／法律責任；創辦人不能自行代替食品技師作法規簽證或保證合規。
- Biggest unknown: 微型品牌的新品頻率、資料完整性與對「先做一次初篩」的信任；尚無獨立成交量資料。
- Cheapest behavioral test: 只做「需求收集＋合格食品技師轉介」：公開一頁「印刷前 10 項自檢」與表單，提供一份免費範例風險分類；用食品社團／設計師社群／SEO 收集 10 份真實但去識別化標示稿，邀請填寫者選擇希望的交付速度與可接受的 NT$500–1,500 初篩價格區間，不直接給法規結論。
- Kill criterion: 30 個台灣目標訪客中少於 5 份真實標示稿提交，或無法找到 1 位合格食品技師願意以明確責任邊界合作，則暫停。

## Candidate C — 多平台電商月結「例外包」

- Target user: 同時經營蝦皮、momo、官網的台灣品牌／電商營運人員。
- Economic buyer: 品牌負責人、財務主管或記帳士事務所。
- Problem: 月結時要將訂單、退款、物流、平台費、電子發票與銀行入帳拼起來；總額可能對得上但商品／通路毛利與異常原因不清楚。
- Current workaround: 匯出各平台報表，以 Excel 人工核對；交給兼任會計／記帳士，或購買 ERP、電子發票與整合服務。
- Strongest evidence: [映流數位台灣多通路對帳說明](https://inflow.com.tw/blog/inflow-channel-reconciliation)、[PureInvoice 公開方案](https://www.puredata.com.tw/products/pureeinvoice)、[瓦奇維台灣多通路記帳價格](https://wachiwi.com/research/2026-q2-accounting-tax-pricing/)、[104 電商會計職缺](https://www.104.com.tw/jobs/search/?keyword=%E9%9B%BB%E5%95%86%E6%9C%83%E8%A8%88)。另有[財政部電子發票統計](https://www.fia.gov.tw/singlehtml/43?cntId=98b6af69d7074f5f87c40760ceda7e9e)作為 Tier A 基礎設施證據。
- Evidence quality: A/B mix; Taiwan Evidence Gate passes.
- Value mechanism: 每月交付「差異清單＋退款／平台費／入帳例外＋商品毛利摘要」，以核對工時、未解釋差異金額與月結完成日衡量。
- Why now: 台灣電商已普遍使用電子發票與多通路平台；在地供應商已把對帳與整合作為付費模組。
- Main contradiction: 競品密集，平台欄位與 API 維護成本高；若只是代做 Excel，毛利與留存可能不足。
- Biggest unknown: 哪一個垂直（食品、保健品、生活用品等）的例外類型最重，且願意讓外部人員接觸銷售資料。
- Cheapest behavioral test: 不開發整合；針對一個垂直公開「月結例外報告」樣本，讓目標品牌上傳去識別化的 1 個月報表，回傳一頁人工例外摘要；量測有效上傳、願意提供第二個月資料、以及是否要求固定月結。暫不收費與不承諾完整帳務申報。
- Kill criterion: 30 個目標訪客中少於 3 個提供真實報表，或 2 次月結後仍找不到可重複、可量化的例外類型，則暫停。

## Candidate D — 10–50 人企業的薪資月結例外整理

- Target user: 沒有專職 HR 的台灣服務業／小型製造業行政人員。
- Economic buyer: 公司負責人、行政主管或記帳士事務所。
- Problem: 每月整合出勤、加班、請假、獎金、勞健保與扣繳，遇到新進／離職與法規級距變化就要人工確認。
- Current workaround: Excel／Google Sheet + 打卡資料、薪資代辦、104／MAYOHR 等 SaaS。
- Strongest evidence: [104薪資系統](https://marketing.pro.104.com.tw/hrm/payroll.html)、[Mirro 年費與試用](https://www.mirro.com.tw/products/salary-tool)、[瓦奇維薪資代辦價格](https://wachiwi.com/research/2026-q2-accounting-tax-pricing/)、[官方勞健保／薪資規定整理](https://0800280280.sme.gov.tw/accounting/run.php?file=detail&id=452&name=kw)。
- Evidence quality: A/B mix; Taiwan Evidence Gate passes.
- Value mechanism: 降低每月追資料、核薪與例外確認工時；以月結耗時、待補資料件數與重新計算次數衡量。
- Why now: 法規與級距固定要求企業持續更新，且台灣已有公開 SaaS／代辦價格。
- Main contradiction: 競爭成熟、個資與法遵風險高；小公司可能直接選現有記帳士或便宜工具。
- Biggest unknown: 是否存在「已經有打卡／薪資系統，但例外整理仍痛」的窄客群。
- Cheapest behavioral test: 做一份不接觸完整薪資資料的匿名化「薪資月結例外清單」，在行政／人資社群募集 10 份流程樣本，測量願意分享流程、預約 20 分鐘示範與索取範本者；不計薪、不代算、不提供法律建議。
- Kill criterion: 30 個目標訪客中少於 5 個願意分享流程或匿名例外案例，或所有受訪者都認為現有記帳士／SaaS 已足夠，則暫停。

## Not recommended now

- Generic Taiwan payroll SaaS: pain and price exist, but incumbents 104／Mirro／代辦 are already strong; current evidence does not show a wedge.
- Generic e-invoice／ERP integration: local vendors already sell it from low monthly subscription to perpetual license; without a narrow exception type, this is a feature race.
- Generic AI tender-writing product: Taiwan demand for tender assistance exists, but the trust and domain-experience barrier makes generic generation unproven.
- Foreign inspiration — Taiwan unvalidated: no foreign-only idea is promoted in this run. Foreign examples were not needed to qualify the four Taiwan candidates.

## Recommended review order

1. Candidate A if the founder can choose one industry vertical and publish useful public checklists.
2. Candidate B only with a qualified food-safety practitioner partner and strict lead-generation / referral scope.
3. Candidate C if the founder can access one platform-heavy vertical through existing communities.
4. Candidate D as a research follow-up, not a build candidate, because privacy and incumbent trust are unresolved.
