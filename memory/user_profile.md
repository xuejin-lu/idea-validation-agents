# Founder Profile

## Explicit startup constraints

- Geography: Taiwan only
- First customer access: online access is sufficient
- Customer type: B2C / SMB B2B / enterprise B2B all acceptable
- Cold outreach: avoid if possible
- Product format: unrestricted
- Manual first version: acceptable
- Initial budget: NT$0–5,000
- Validation horizon: up to 3 months
- First revenue threshold: any real payment counts
- Market size preference: niche/small markets are acceptable
- Domain learning: willing to spend 1–3 months
- High-barrier domains: acceptable if justified
- Founder advantage: prefer opportunities leveraging EE/software/technical strengths when useful
- Regulation: acceptable; regulation may be a moat
- Technology preference: technology/AI is a means, not a requirement
- Excluded categories: none
- Search philosophy: accessible pain first + founder advantage

See `FOUNDER_CONSTRAINTS.md` for the authoritative operating rules.
