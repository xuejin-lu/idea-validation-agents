# 資料處理與隱私告知

本服務只在初步範圍判斷與固定一個月資料準備所需的最小程度，處理買方主動提供且已去識別化的檔案。這不是隱私法合規認證或法律意見。

## 請提供什麼

- 指定一個月的少量樣本，先用 3–10 筆確認欄位；
- 平台、金流、銀行或既有對帳表的必要欄位；
- 可回溯來源的檔名／列號資訊；
- 買方希望交給既有記帳士／會計師的欄位要求。

## 先遮蔽什麼

姓名、電話、地址、身分證字號、完整訂單地址、會員識別碼、完整信用卡或銀行帳號、登入 token、API key，以及任何不需要用來比較欄位的個人或付款資訊。公司／品牌可使用代號。

## 絕對不要傳送

密碼、OTP、後台登入、銀行登入、電子發票後台登入、API key、完整付款卡資料、未遮蔽個資或可直接接管帳戶的授權。服務不需要代登入、代操作或取得帳戶控制權。

## 暫存、存取與刪除

- 樣本只應透過雙方事先同意的安全管道提供；不在公開貼文、公開雲端連結或聊天群組散佈。
- 只保留完成範圍確認與一次交付所需的檔案與工作表；檔名使用公司代號與期間，不用真實個資作為檔名。
- 只讓執行本案的人員存取；不把檔案放入公開作品集或分享給無關第三方。
- 案件結束後，依雙方書面約定刪除暫存原檔、下載副本、衍生工作檔與聊天附件；若因爭議或專業交接需短暫保留，先記錄保留理由、範圍與刪除日期。
- 任何刪除或保留例外都由人工記錄，不宣稱符合特定認證或法規標準。

## 不作模型訓練或公開展示

買方資料不會用於模型訓練、公開作品集、行銷案例、產品 demo 或與本案無關的分析。要公開展示，必須另取得書面同意，且本測試預設不展示真實資料。

## 專業邊界觸發

若資料或問題需要正式記帳、收入／費用認列、稅額、發票／折讓處理、申報、簽證、法律或合規判斷，立即停止該部分，保留「待專業人士確認」的資料索引，交給買方既有的台灣合格記帳士／會計師審閱。未完成邊界審查前，不開始真實資料交付，也不提供結論。
